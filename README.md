ระบบบริหารการจัดการทรัพยากรบุคคล (Human Resource System)
โรงเรียนเซนต์โยเซฟทิพวัล (St. Joseph Thiphawan School)
โครงงานปริญญานิพนธ์ฉบับนี้เป็นการพัฒนาระบบเพื่อเปลี่ยนผ่านการบริหารงานบุคคลจากระบบเอกสารสู่ระบบดิจิทัล (Digital Transformation) เพื่อเพิ่มประสิทธิภาพ ความแม่นยำ และความโปร่งใสในการจัดการข้อมูลภายในองค์กร 
+2

1. ลักษณะของระบบ (System Overview)

สถาปัตยกรรม: ออกแบบตามโครงสร้างแบบ 3-Tier Architecture (Frontend, Backend, Database).
+1


การเชื่อมต่อ: สื่อสารผ่าน RESTful API ในรูปแบบ JSON.
+2


การแสดงผล: รองรับการใช้งานผ่านหน้าจอทุกรูปแบบ (Responsive Web Design) ทั้งคอมพิวเตอร์และสมาร์ทโฟน.

ความปลอดภัย:

ใช้การควบคุมสิทธิ์ตามบทบาท (Role-Based Access Control - RBAC).

ยืนยันตัวตนผ่าน Session และการเข้ารหัสผ่านแบบ Bcrypt.
+1

รองรับการเข้าใช้งานผ่าน Google Sign-In.
+1

2. ขอบเขตและสิทธิ์การใช้งาน (Scope & Roles)
ระบบแบ่งสิทธิ์การเข้าถึงข้อมูลตามตำแหน่งงานในองค์กร:

ครูทั่วไป (Teacher):

ส่งคำร้องขอลาออนไลน์.

ตรวจสอบประวัติการลงเวลาเข้า-ออกงาน และสถานะคำร้องของตนเอง.
+1

ตรวจสอบข้อมูลการคำนวณเงินเดือน.

แก้ไขประวัติส่วนตัว.

หัวหน้าหมวด (Head of Subject):

มีสิทธิ์พื้นฐานเหมือนครูทั่วไป.
+2

ตรวจสอบและอนุมัติคำร้องขอลาของครูที่อยู่ภายใต้การดูแลในหมวดวิชาตนเอง.

แอดมิน / หัวหน้าฝ่าย (Admin/Head of Department):

อนุมัติหรือปฏิเสธคำร้องของบุคลากรตามสายงานที่ได้รับสิทธิ์.
+1

สร้าง จัดการ หรือลบกำหนดการประชุม/อบรมในปฏิทินกลาง.
+1

จัดการและตรวจสอบข้อมูลประวัติการทำงานของพนักงานในสังกัด.

ผู้บริหาร (Executive/Owner):

ตรวจสอบภาพรวมและประวัติคำร้องทั้งหมดในองค์กร.
+1

เข้าถึงและแก้ไขข้อมูลบุคลากรทุกคน.
+1

ตรวจสอบสถิติการเงินและปรับแก้ไขฐานเงินเดือนของพนักงาน.
+1

จัดการปีการศึกษา (กำหนดวันเปิด-ปิดภาคเรียน).
