# ระบบบริหารจัดการหอพัก (Dormitory Management System)
**สาขาวิชาเทคโนโลยีสารสนเทศ คณะวิทยาศาสตร์และเทคโนโลยี**

## 📝 บทคัดย่อ (Abstract)
[cite_start]โปรเจกต์นี้เป็นการพัฒนาระบบเพื่อช่วยจัดการหอพักให้มีความสะดวกและรวดเร็วขึ้น [cite: 1] [cite_start]โดยเน้นการจัดเก็บข้อมูลอย่างเป็นระบบเพื่อลดความผิดพลาดในการทำงาน[cite: 1].

## 🚀 วัตถุประสงค์ (Objectives)
* [cite_start]เพื่อให้มีความสะดวกและรวดเร็วในการจัดเก็บข้อมูล[cite: 1].
* [cite_start]เพื่อลดความซับซ้อนในการทำงานและจัดเก็บข้อมูลอย่างเป็นระบบ[cite: 1].
* [cite_start]เพื่อนำความรู้ที่ได้จากการเรียนมาประยุกต์ใช้งานจริง[cite: 1].

## 🛠️ ขอบเขตของระบบ (Project Scope)
ระบบถูกออกแบบมาให้รองรับการทำงานดังนี้:
1. [cite_start]**ระบบล็อกอิน:** เพื่อเข้าสู่ระบบการจัดการ[cite: 1].
2. [cite_start]**การจัดการห้องพัก:** สามารถเพิ่ม ลบ และแก้ไขข้อมูลห้องพักได้[cite: 1].
3. [cite_start]**การจัดการผู้เช่า:** เพิ่มและแสดงข้อมูลผู้เข้าพัก[cite: 1].
4. [cite_start]**การคำนวณค่าเช่า:** บันทึกค่าน้ำ ค่าไฟ และยอดรวมรายเดือน[cite: 1].
5. [cite_start]**การจัดการสถานะห้อง:** ตรวจสอบห้องว่างและห้องที่ไม่ว่าง[cite: 1].

## 💻 เทคโนโลยีที่ใช้ (Tech Stack)
* **Backend:** Node.js / Express (ตามโครงสร้างโฟลเดอร์ App_Server ของคุณ)
* [cite_start]**Database:** MySQL [cite: 1]
* **Editor:** Visual Studio Code
