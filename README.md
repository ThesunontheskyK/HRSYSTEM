🏥 HR System: Joseph Thiphawan School

   ระบบบริหารจัดการทรัพยากรบุคคลยุคใหม่ เพื่อการเปลี่ยนผ่านสู่ดิจิทัลอย่างเต็มรูปแบบ

📝 เกี่ยวกับโครงงาน (Project Overview)

   ระบบบริหารการจัดการทรัพยากรบุคคล (HR System) นี้ถูกพัฒนาขึ้นเพื่อแก้ปัญหาความล่าช้าจากการใช้เอกสารกระดาษในโรงเรียนเซนต์โยเซฟทิพวัล โดยเปลี่ยนมาใช้ระบบเว็บแอปพลิเคชันที่ทันสมัย แม่นยำ และโปร่งใส 


🌟 จุดเด่นของระบบ

   Single Source of Truth: รวมศูนย์ข้อมูลบุคลากรไว้ในที่เดียว 
   
   
   Role-Based Access: ควบคุมสิทธิ์การใช้งานตามตำแหน่งหน้าที่อย่างชัดเจน 
   
   
   
   Responsive Design: ใช้งานได้ทุกอุปกรณ์ ทั้ง Desktop, Tablet และ Smartphone 
   
   
   
   Google Integration: รองรับการเข้าสู่ระบบผ่านบัญชี Google เพื่อความสะดวกและปลอดภัย

🛠 เทคโนโลยีที่เลือกใช้ (Tech Stack)

🎨Frontend
   
   Languages: HTML5, CSS3, JavaScript (ES6+) 
   
   
   Framework: Bootstrap (UI Components) 
   
   
   Design: Responsive Web Design 

📂Backend

   Engine: Node.js (V8 Engine) 
   
   
   Framework: Express.js 
   
   
   Architecture: RESTful API 

🗄️Database & Security

   Database: MySQL 
   
   
   
   Authentication: Google OAuth 2.0 & Session 
   
   
   
   Encryption: Bcrypt + Salt สำหรับการเข้ารหัสรหัสผ่าน

👥 ขอบเขตสิทธิ์ผู้ใช้งาน (User Roles)
บทบาท	คำอธิบายสิทธิ์การใช้งาน

   👨‍🏫 ครูทั่วไป	
   ส่งใบลา, ตรวจสอบเงินเดือน, เช็คประวัติเข้างาน, แก้ไขโปรไฟล์ส่วนตัว 


   🧑‍💼 หัวหน้าหมวด	
   สิทธิ์ครูทั่วไป + อนุมัติ/ปฏิเสธคำร้องขอลา ของครูในหมวดวิชา 


   🛡️ แอดมิน (หัวหน้าฝ่าย)	
   จัดการข้อมูลพนักงานในสังกัด, สร้าง/ลบ กำหนดการประชุม, อนุมัติคำร้องสายงาน 
   
   
   👑 ผู้บริหาร	
   ดูภาพรวมทั้งโรงเรียน, ปรับแก้ไขเงินเดือน, จัดการปีการศึกษา, ตรวจสอบรายงานการเงิน
